# カテゴリ別一覧・プロフィール枠ページ

## 実装内容

- `/article`、`/slide`、`/diary` を追加し、既存の `PostList` にカテゴリ別の投稿を渡して表示する。
- 投稿の正規化と公開日降順ソートを `src/utils/posts.ts` に集約し、トップページとカテゴリページで共有する。
- カテゴリページでは `ProfileHeader` を使わず、アバターとSNSリンクを表示しない。
- `/profile` には今後プロフィール本文を入れるための空の枠を表示する。
- 共通ヘッダーに `Article`、`Slide`、`Diary`、`Profile` の導線を追加し、現在ページをアクセント色で表示する。モバイルではリンク列を横スクロール可能にする。

## 検証

- `pnpm check`
- `pnpm lint`
- `pnpm build`
- ビルド時に4ページと既存の日記詳細ページが生成されることを確認する。
- 各カテゴリページでヘッダーの該当リンクがアクティブ表示され、狭い画面でもヘッダーが折り返さないことを確認する。
