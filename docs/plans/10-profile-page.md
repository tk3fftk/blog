# Markdownで編集できるプロフィールページ

## 設計・実装

- `/profile` の本文は `src/content/profile.md` にまとめ、`src/pages/profile.astro` から `Content` を直接importして表示する。追加依存やコンテンツコレクションは不要。
- プロフィール、できること・スキル、学歴、職務経歴、開発したアプリケーション・ツール、XのDMへの連絡先を掲載する。
- 本文は `cv.md` とユーザー提供の学歴を根拠にする。LAPRASは公開ページのHTMLに本文がなく、取得できなかったため未確認情報は補完しない。
- 個人サイト向けの簡潔な紹介とし、外部記事・登壇一覧、資格一覧、生年月日、転職希望条件は掲載しない。
- 既存のヘッダー・フッター・ダークテーマを維持し、本文幅を日記ページと同じ `max-w-3xl` にする。Markdownのスタイルはプロフィール本文に限定する。
- ページのh1は「Profile」とし、Markdownはh2から始める。descriptionには日本語のプロフィール要約を設定する。

## 編集方法

- 文章・見出し・箇条書き・リンクは `src/content/profile.md` を通常のMarkdownとして編集する。
- 新しい節は `##`、節内の見出しは `###`、リンクは `[表示名](URL)` で記載する。HTMLを書く必要はない。
- ページタイトル・description・レイアウト・装飾を変更する場合は `src/pages/profile.astro` を編集する。
- アプリは公開したツールとして紹介し、現在も開発中とは断定しない。連絡先はXプロフィールへのリンクとDMへの案内にする。

## 検証

- `npm run check`、`npm run lint`、`npm run build` が成功。
- 変更した3ファイルの `pnpm exec prettier --check` が成功。
- ビルド成果物をヘッドレスブラウザーで表示し、幅390px・1280pxでh1が1つ、h2が6つであること、アプリ3件とXへのリンク、横はみ出しがないことを確認。スクリーンショットで余白と折り返しも確認した。
- ブラウザー検証では外部リクエストを遮断しているため、Webフォントの読み込みやリンク先サービスの動作は検証対象外。
- ビルドによるRSSスナップショットの自動更新は元に戻し、今回の変更に含めていない。
- 開発サーバーは未使用。今後利用する場合は `astro dev --background` を使用する。
